About This App

Created by Piyush Assudani, Class XI Science.

This simple attendance system lets you manage transport details, student lists, daily attendance and export a clean PDF report. It is fully offline and saves data in your browser (Local Storage). Works on mobile and laptop.

How to Use
  1. Go to Setup → fill School, Teacher, Driver, Vehicle.
  2. Open Students → add student names.
  3. Open Attendance → pick date → mark Present/Absent → Save.
  4. Open Export PDF → select date → Download PDF.
